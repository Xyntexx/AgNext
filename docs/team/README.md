# Meet the Team

AgOpenNext is built by volunteers — farmers, engineers, and developers from around the world — working together to advance open precision agriculture software.  
This directory lists current contributors, their focus areas, and links to individual profiles.

Roles describe **responsibility**, not **authority**. Governance remains transparent and consensus-based through ADRs, SRS updates, and documented decisions.

---

## Add Yourself

To join the team listing:

1. Copy the [TEMPLATE.md](./TEMPLATE.md) file.  
2. Rename it as `Your Name - Username.md` (for example, `Jane Doe - tractorqueen42.md`).  
3. Fill out your role, focus areas, and optional bio.  
4. Submit a pull request — once merged, your profile will appear here automatically.
